# Embrapa I/O — skills (arquivado)

> **Este repositório foi arquivado em 02/11/2026.** A skill de geração de _boilerplates_ passou a ser o plugin
> **`boilerplate@embrapa-io`**, no marketplace da agente Alice: <https://github.com/embrapa-io/alice>.

```bash
claude plugin marketplace add embrapa-io/alice
claude plugin install boilerplate@embrapa-io
```

Depois, no Claude Code, chame `/boilerplate:alice`. Documentação: <https://embrapa.io/docs/boilerplate#skill>.
